# travel-vr-ar

Aplikacja interaktywna dedykowana biuru podróży, łącząca technologie VR, AR oraz Web.
Głównym celem jest zapewnienie klientom wysokiego poziom immersji i fotorealizmu
przy wyborze wakacji. Projekt powstaje na bazie gotowego modułu bazowego, co pozwala
na szybkie wdrożenie i precyzyjne dopasowanie pod wymagania klienta.

## User Journey

1. **Inteligentna Ankieta AI**
   - Interaktywny wywiad zasilany przez algorytmy AI.
   - System analizuje preferencje i dobiera idealne kierunki podróży.
   - Automatyczna archiwizacja danych – odpowiedzi zapisywane w czasie rzeczywistym
     już od pierwszego pytania.
2. **Ciągły Spacer Wirtualny**
   - Użytkownik przechodzi przez zaproponowane miejsca w formie jednej, płynnej
     i nieprzerwanej sceny.
   - Nacisk na maksymalny realizm oprawy graficznej.
3. **Eksploracja Szczegółowa (Szczegółowe Mapy)**
   - Po głównym spacerze użytkownik może swobodnie przeglądać wybrane mapy
     i lokacje.
4. **Podsumowanie i Wydruk Oferty**
   - Spersonalizowane podsumowanie (druk fizyczny lub cyfrowy):
     - sugerowane daty lotów,
     - dopasowane hotele,
     - lista rekomendowanych atrakcji,
     - kompletny draft planu wycieczki.

## Technologia i wdrożenie

- **Silnik graficzny:** Unity
- **Jakość:** wysoki poziom realizmu oprawy wizualnej i oświetlenia
- **Platformy docelowe:**
  - wersja natywna na PC (stacjonarne stanowisko w biurze podróży, pełna wydajność),
  - dedykowany port przeglądarkowy (zoptymalizowany pod Google Chrome).
